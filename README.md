# LearnPorts - To Learn TCP/UDP Services and Ports

This app is helping to learn computer's services and ports associated with them.

This program is allowing to learn computer's services and ports associated with them.

Program is showing a service name and proposes three different port numbers on which this service may hold, user must choose one of the answer. Then the program will showing if answer is right or not. Also program is counting right answers and wrong and giving statistic of answering. This app includes all main services and ports. Program is good for students or network administrators who want to memorize services and ports of networks which computers are using/utilizing, as well as for anyone who is curious about computers and networks.
